# Проект модуля. Retrieval-система по статьям с arXiv
## Задача

Разработана поисковая система для поиска релевантных статей по аннотациям из датасета `arxiv-metadata-s.json`. Система принимает текстовые запросы и возвращает наиболее подходящие статьи. Оценка качества выполнена на `test_sample.csv`.

## Цель

Построена retrieval-система с целевой метрикой **Mean Reciprocal Rank (MRR@5) > 0.91**. Проведено профилирование компонентов для выявления узких мест производительности.

## Данные

1. arxiv-metadata-s.json содержит метаданные статей: 
    - id - уникальный идентификатор
    - title - название
    - abstract - аннотация 
2. test_sample.csv включает колонки: 
    - query - поисковый запрос
    - id - верный ID статьи
    - abstract - аннотация правильной статьи

## План проекта

1. **EDA** – загружены и визуализированы данные, выбраны подходы к поиску и архитектура.  
2. **Реализация** – написан код поисковой системы, функции `MRR` и профилирования. Загружены статьи, отображён размер базы.  
3. **Оценка качества** – выполнен поиск по тестовым запросам, рассчитана метрика, визуализировано время работы частей системы.  
4. **Выводы** – определены медленные компоненты, предложены способы ускорения.

## Результаты

### Этап 1. EDA 
Выполнен анализ данных, обоснован выбор модели и компонентов.

### Этап 2. Реализация

### Этап 3. Оценка качества
- `MRR@5 = <значение>` (целевое > 0.91)  
- Временной профиль системы визуализирован.
